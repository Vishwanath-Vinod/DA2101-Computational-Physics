# DA2101 – Computational Physics

This repository contains solutions to assignments from the DA2101 Computational Physics course. Each assignment focuses on numerical methods commonly used in scientific computing.

## Assignment 1: Solving ODEs
- Numerical methods for first-order ODEs.
- Euler, Improved Euler, and Runge–Kutta methods.
- Comparison with analytical solutions.

## Assignment 2: Higher-Order ODEs and Frobenius Method
- Reduction of higher-order ODEs to systems of first-order equations.
- Series solutions using the Frobenius method.

## Assignment 3: Numerical Differentiation
- Forward, Backward, and central difference formulas.
- Higher-order finite difference schemes.

## Assignment 4: Numerical Integration
- Newton–Cotes formulas (Trapezoidal, Simpson’s rules).
- Gaussian quadrature.
- Comparison of accuracy and convergence.

## Assignment 5: Solving Differential Equations Numerically
- Boundary value problem solvers.
- Shooting and finite difference methods.
- Error analysis with respect to step size.
- Numerical solutions using RK methods.
- Applications to second-order linear ODEs.
